# Contributing

Full protocol: [COLLAB.md](COLLAB.md).

1. Do not add features that fight `docs/hypothesis.md`.
2. Do not split tag extraction into multiple LLM calls.
3. Keep gold queries separate from the model that tagged memories.
4. Log experiments under `experiments/` and decisions under `research/log.md`.
5. Incoming ChatGPT/Grok notes go to `research/inbox/` or a handoff issue first.
6. Every commit title ends with `(grok)`, `(chatgpt)`, or `(human)`.
